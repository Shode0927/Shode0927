# FABLE — 千夜の寓話

頁をひらくたび、**世界にひとつだけの寓話**が紡がれるiOSアプリ。

物語も、挿絵も、すべてこの端末の中で生まれる。サーバーには何も尋ねない。
シード値ひとつから、寓話生成エンジンが日本語の物語を組み上げ、
Skiaがその夜のための一枚絵(空・月の満ち欠け・山並み・光の精霊)を描き起こす。

## 遊び方(Expo Go)

1. iPhoneに [Expo Go](https://apps.apple.com/app/expo-go/id982107779) を入れる
2. このディレクトリで:

   ```bash
   npm install
   npx expo start
   ```

3. 表示されたQRコードをiPhoneのカメラで読む

## 見どころ

- **寓話生成エンジン** (`src/engine/fable.ts`)
  6つのテーマ(光・時・声・夢・心・風)× 3つの物語型(探索譚・問答譚・喪失譚)×
  膨大な語彙プールから、筋の通った寓話を組み上げる。同じ夜は二度と紡がれない。
- **生成挿絵** (`src/art/FableScene.tsx`)
  中点変位法の山並み、シードで決まる月の満ち欠け、瞬く星、呼吸する光の精霊。
  テーマごとに配色が変わり、すべてリアルタイムに揺らめく。
- **表紙の星空** (`src/art/Starfield.tsx`)
  端末を傾けると星の層が視差で揺れる。ときどき星が流れる。
- **墨書きの演出** (`src/components/InkText.tsx`)
  物語が一文字ずつ滲み出る。句読点で指先にかすかな手応え。触れれば一気に現れる。
- **夜の書庫**
  紡いだ寓話は端末に積まれていく。長押しで手放す。「分かち合う」で共有もできる。
